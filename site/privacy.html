Политика конфиденциальности

Приложение «Нумен» (Numen) для Android и веб-версия. Действует с 31 октября 2026 года.

Коротко: Нумен не собирает, не отправляет и не продаёт никаких данных. Всё, что ты делаешь в приложении, хранится только на твоём устройстве.

Какие данные хранит приложение

Чтобы показывать прогресс, приложение сохраняет на устройстве:

  • уровни навыков, результаты тренировок, звёзды пути и вызова дня, серию дней;
  • настройки: тему, палитру, звуки, время напоминания.

Эти данные не покидают устройство. Приложение не требует регистрации, не запрашивает имя, почту, телефон, местоположение, контакты или фотографии и не содержит рекламы и сторонней аналитики.

Интернет

Android-версия работает без интернета и не отправляет запросов в сеть. Веб-версия загружается с GitHub Pages; при открытии сайта GitHub, как любой веб-хостинг, получает технические данные запроса, например IP-адрес. Подробнее в заявлении GitHub о конфиденциальности.

Разрешения Android

УведомленияТолько для ежедневного напоминания о тренировке, если ты его включил. Напоминание формируется на устройстве.
Запуск после перезагрузкиЧтобы напоминание и виджет продолжали работать после перезагрузки телефона.
ВибрацияКороткий отклик при ответах и нажатиях. Отключается в настройках.

Резервная копия

Если ты сохраняешь прогресс в файл, файл создаётся там, где ты сам выбрал: в памяти телефона, облаке или мессенджере. Приложение не имеет доступа к другим твоим файлам и читает только тот файл, который ты выбрал для загрузки.

Удаление данных

Чтобы удалить все данные, нажми «Сбросить весь прогресс» в настройках или удали приложение. В веб-версии можно также очистить данные сайта в настройках браузера.

Дети

Приложение подходит для любого возраста и ни у кого не собирает персональных данных, в том числе у детей.

Изменения и связь

Если политика изменится, новая версия появится на этой странице с новой датой. Вопросы можно задать через страницу проекта на GitHub или по адресу, указанному в карточке приложения в RuStore.
