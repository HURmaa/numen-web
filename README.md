# Нумен, веб-версия

Тренажёр устного счёта, памяти и наблюдательности. Работает в браузере и без интернета после первого открытия.

## Установка на iPhone

1. Открой ссылку на сайт в **Safari**.
2. Нажми «Поделиться» (квадрат со стрелкой вверх).
3. Выбери «На экран „Домой“» и нажми «Добавить».

На Android в Chrome: меню «⋮», затем «Добавить на главный экран» или «Установить приложение».

## Устройство

Папка `site` публикуется на GitHub Pages при каждом изменении ветки `main`. Исходники общие с Android-версией (репозиторий Mentat), сюда копируется только веб-часть.
